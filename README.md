🏅 Microsoft Power BI Olympic Dashboard

This Power BI report analyzes the performance of different countries in the Olympic Games from 1896 to 2016.


📊 Features
Track country performance across different years.
Filter by country, year, type of games, or medals won.
Interactive dashboard ranks countries’ performance using bar graphs and visual insights.


⚙️ Data Processing
Used Power BI Query Editor to perform the ETL process (Extract, Transform, Load).
Cleaned and transformed raw Olympic data for accurate reporting.


✨ This project demonstrates my ability to build interactive dashboards, perform data transformations, and generate insightful visualizations using Microsoft Power BI.
